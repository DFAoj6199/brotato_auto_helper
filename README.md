## ✨ 功能特性

### 🔄 自动化流程

| 环节 | 功能 | 说明 |
|------|------|------|
| **升级** | 自动检测升级界面并点击 | 每击前实时检测界面，不再依赖 OCR 数字识别，告别识别不准 |
| **箱子** | 自动拾取 / 自动跳过 | OCR 识别道具名，匹配期望列表拾取；支持一键跳过所有物品 |
| **商店** | 自动搜索购买 + 刷新 | 按目标道具名搜索 4 个槽位，找不到自动刷新，找到后购买并出发 |
| **出发** | 波次倒计时 | 自动等待战斗结束，期间支持暂停/紧急停止 |

### 🖥️ 游戏内浮窗

- 半透明置顶浮窗，实时显示当前操作状态和最近拾取/购买记录
- **可视化调整**：拖拽边框等比例缩放、拖拽中央移动位置、自动边缘吸附
- **自定义外观**：不透明度、字体大小均可调节
- **预览模式**：开启后浮窗显示预览文本，拖拽调好再启动程序

### ⌨️ 快捷键系统

| 默认按键 | 功能 | 可自定义 |
|----------|------|:--------:|
| `F7` | 单次触发：箱子 → 升级 → 商店 → 出发 → 结束 | ✅ |
| `F8` | 连续模式：循环执行，波次间自动轮转 | ✅ |
| `ESC` | 紧急停止：任意环节立即中断 | ✅ |
| `F6` | 暂停/恢复：任意环节暂停，再按恢复 | ✅ |
| `T` | 测试箱子检测 | ✅ |
| `Y` | 测试道具识别 | ✅ |
| `U` | 测试升级界面检测 | ✅ |

> ⚠️ **注意**：游戏内 `F8` 是"反馈"快捷键，会与连续模式冲突。请在使用前到「⌨ 快捷键」设置窗口中将连续模式改为其他按键（如 `F9`）。
>
> 所有快捷键均可在「⌨ 快捷键」设置窗口中自定义，支持冲突检测。

### ⚙️ 其他亮点

- **升级上限**：可设置最多升级次数，到达上限自动停止
- **界面框选**：全屏截图可视化框选，点击后 1 秒延迟进入，方便切屏
- **配置持久化**：所有设置自动保存到 `config.json`
- **商店冷却**：检测到商店离开后有冷却期，防止重复触发
- **可拖拽日志**：底部日志区域高度可拖拽调节

## 📦 安装与运行

### 方式一：源码运行（推荐）

```bash
git clone https://github.com/DFAoj6199/brotato_auto_helper.git
cd brotato_auto_helper
pip install -r requirements.txt
python main.py
```

> EasyOCR 首次运行会自动下载中文识别模型（约 100MB），请耐心等待。

### 方式二：下载 EXE

从 [Releases](https://github.com/DFAoj6199/brotato_auto_helper/releases) 下载最新版 `BrotatoHelper.zip`，解压后双击 `BrotatoHelper.exe` 即可。

> 首次运行 EasyOCR 需加载模型，启动较慢（约 30 秒），后续会快很多。

### 打包为 EXE（可选）

```bash
pip install pyinstaller
python -m PyInstaller BrotatoHelper.spec
# 输出在 dist/BrotatoHelper/
```

## 🚀 快速上手

### 1. 框选各区域

打开程序后，依次框选以下区域（左侧面板有对应的「框」/「取」按钮）：

| 区域 | 说明 | 必须 |
|------|------|:--:|
| 升级点击坐标 | 升级界面中点击的位置（鼠标坐标） | ✅ |
| 升级检测区域 | OCR 检测"升级"二字的屏幕区域 | ✅ |
| 箱子属性区 | OCR 检测"属性"以判断是否在箱子界面 | 可选 |
| 道具名区域 | OCR 识别道具名的屏幕区域 | 可选 |
| 商店检测区域 | OCR 检测"商店"以判断是否在商店界面 | 可选 |
| 商店 4 个槽位 | 商店中 4 个道具名称区域 | 可选 |
| 商店购买/刷新/出发坐标 | 对应的鼠标点击坐标 | 可选 |

### 2. 测试各检测

使用右侧面板的测试按钮，逐一验证每个检测是否正确：

- 🧪 **检测升级界面**：在升级界面和商店中分别测试，确保结果准确
- 🔍 **检测箱子**：在箱子界面测试"属性"检测
- 📝 **道具识别**：测试道具名 OCR 是否准确

### 3. 启动托管

- 切到游戏窗口
- 按 **F7** 执行一次完整流程（箱子 → 升级 → 商店 → 出发）
- 确认无误后按 **F8** 开启连续模式

## 🎯 工作流程（单次触发 F7）

```
① 箱子拾取（循环直到离开箱子界面）
     ↓
② 检测升级界面 → 是 → 升级循环（每击前检测）
     ↓                        ↓ 离开升级界面
③ 商店购买 → 找到目标 → 购买 → 出发 → 🏁 结束
```

## 🛠️ 常见问题

### 升级检测误判（不在升级界面也点击）

1. 使用「🧪 检测升级界面」按钮在商店中测试
2. 确认 OCR 返回的结果不是"升级"或"升级!"
3. **关键**：将升级检测区域缩小到只覆盖游戏本身的"升级"文字位置，避免覆盖商店道具名区域

### 商店误锁道具

- 升级点击坐标与商店锁定按钮位置重叠时的已知问题
- 程序已内置点击后立即移开鼠标的保护机制
- 建议将升级点击坐标与锁定按钮错开

### EasyOCR 首次启动慢

- 首次运行会下载模型文件，请等待 1-2 分钟
- 后续启动会直接加载本地模型
